Native backend third-party notices
==================================

This directory contains the Go monitoring backend copied from
nexmoe/vscode-monitor-pro. The upstream backend sources and tests are preserved
verbatim. See the repository's general NOTICE for the upstream project
attribution. The dependency notices below apply to the native executables and
do not replace any upstream copyright or license terms.

Inventory source: native/go.mod and native/go.sum, resolved with Go 1.26.2.
Linked modules were checked with go list -deps for windows/amd64,
windows/arm64, and the local integration target darwin/arm64, all with
CGO_ENABLED=0. Full upstream license and patent files are preserved verbatim
in native/LICENSES. Dependencies remain unmodified.

Updating the inventory
----------------------

When native/go.mod, native/go.sum, target platforms, or the Go toolchain version
changes, regenerate the resolved and linked inventories before packaging.
Copy the new upstream LICENSE, NOTICE, COPYING and PATENTS files without
rewriting their text, retain source copyright notices, and update this file.
Distribute this file and the complete native/LICENSES directory alongside both
Windows executables.
